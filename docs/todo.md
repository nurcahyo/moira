# Phase 1-6 TODO

This list tracks what is still left to harden or complete after the current Phase 1-6 implementation pass.

## How to read the markers

| Marker | Meaning |
| --- | --- |
| `TODO:` | Still open. If a GitHub issue owns it, the number is on the line. |
| `PARTIAL:` | Some of it shipped; the line says what is left. |
| `DONE:` | Shipped. The line names the commit, the file, or the test that closes it. |
| `CLOSED BY DESIGN:` | Deliberately not going to be built the way this line originally described. The line names where the decision is written down in the code. |
| `NOT DEAD — DO NOT REMOVE:` | A standing warning against a deletion that looks safe and is not. |

Nothing is deleted when it closes. The reason an item existed is part of the record, so a closed
item keeps its original sentence and gains the evidence after it.

Every `DONE` and `CLOSED BY DESIGN` line below was re-verified against the tree on the branch that
wrote this note, not carried over from a previous claim.
