# RAG Collections

Admin endpoints:

- `POST /api/v1/admin/rag-collections`
- `GET /api/v1/admin/rag-collections`
- `GET /api/v1/admin/rag-collections/{collection_id}`
- `PATCH /api/v1/admin/rag-collections/{collection_id}`
- `DELETE /api/v1/admin/rag-collections/{collection_id}`
- `POST /api/v1/admin/rag-collections/{collection_id}/enable`
- `POST /api/v1/admin/rag-collections/{collection_id}/disable`

Collection visibility can be `application`, `tenant`, or `restricted`.
