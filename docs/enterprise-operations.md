# Enterprise Operations

Phase 6 turns Moira from feature-complete service into an operable distributed platform.

Operational ownership areas:

- deployment and rollout safety
- Redis coordination
- background worker health
- provider health monitoring
- adaptive routing inputs
- audit export
- SLO and alert review
- backup and restore drills
- security scanning
- load and chaos validation
- incident runbooks

The current implementation adds the production foundation and deployment scaffolding. Deeper distributed semantics and test evidence are tracked in `docs/todo.md`.
